# Pokémon Inheritance Practice – NOVI Backend Java Assignment

## About the Project

This repository contains my implementation of the **Pokémon Inheritance Assignment** from the Backend Java module at [Novi University](https://www.novi.nl).  
The goal of this assignment is to practice **object-oriented programming** in Java by working with **superclasses**, **subclasses**, **constructors**, **encapsulation**, **method overriding**, and **custom behavior** per class.

- **IntelliJ IDEA**

---

## Key Features

- A base `Pokemon` superclass
- 4 subclasses with specific behavior:`FirePokemon`, `WaterPokemon`, `GrassPokemon`, `ElectricPokemon`
- A `Main` class with a`main` method that: 
    - Creates four different Pokémon objects 
    - Calls to various inherited and subclass-specific methods 
    - Console output using `System.out.println()` to simulate actions

---

## How to Run

1. Open the project in your IDE (IntelliJ IDEA)
2. Navigate to the `Main` class
3. Locate the `main` method and click the green play button to **Run 'Main'** or use the terminal:
    ```bash
   mvn clean compile exec:java
   ```
